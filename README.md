# apple-browsers-snapshots

Companion repository holding the reference images for the DuckDuckGo iOS and macOS UI snapshot tests.

It contains no source code — only recorded snapshot artifacts. It is consumed by [`apple-browsers`](https://github.com/duckduckgo/apple-browsers) as a git submodule. See the [`SnapshotTestingSupport`](https://github.com/duckduckgo/apple-browsers/tree/main/SharedPackages/SnapshotTestingSupport) package there for how snapshot testing works.
